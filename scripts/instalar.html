Desarrollado por Daniel Jaimes

El complemento corre desde esta página: no hay que instalar programas ni dejar nada encendido. Lo que se instala en Excel es un archivo pequeño, el manifiesto, que le dice dónde encontrarlo. Los cálculos se hacen en tu equipo; los datos del libro no salen de él.

Windows

  1. Cierra Excel.
  2. Descarga el instalador y ábrelo con doble clic.
  3. Si Windows dice «Windows protegió tu PC»: Más información → Ejecutar de todas formas.
  4. Sigue lo que dice la ventana y abre Excel: aparece la pestaña Riesgo.
Descargar instalador para Windows Desinstalar

¿No aparece la pestaña? Mira en Inicio → Complementos. Si tampoco está ahí, descarga el diagnóstico, ábrelo y envía el texto que muestra en el Bloc de notas: no cambia nada en tu equipo.

Mac

  1. Cierra Excel (Cmd + Q).
  2. Abre Terminal (Cmd + Espacio, escribe Terminal, Enter), pega esta línea y pulsa Enter:
mkdir -p ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef && curl -fsSL manifest.xml -o ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef/riesgo-montecarlo.xml
  1. Abre Excel y un libro. Si no ves la pestaña Riesgo: Insertar → Complementos → Mis complementos y elige Riesgo Monte Carlo.

Para quitarlo: rm ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef/riesgo-montecarlo.xml

Excel en la Web

  1. Descarga el manifiesto.
  2. Abre un libro en Excel para la Web: Inicio → Complementos → Más complementos → Mis complementos → Cargar mi complemento.
  3. Examinar → elige manifest.xml → Cargar.
Descargar manifest.xml

Si no aparece «Cargar mi complemento», tu organización lo tiene bloqueado; prueba con una cuenta Microsoft personal. Al abrir otro libro, otro día, puede que haya que cargarlo de nuevo.

Condiciones de uso

Esta es una versión de prueba, de uso privado, compartida solo con las personas invitadas a probarla. Te agradecemos no compartir este enlace, el instalador ni el manifiesto mientras terminan las pruebas.

Como versión de prueba, puede tener errores: revisa los resultados antes de usarlos en una decisión y cuéntanos lo que encuentres.

Actualizaciones

Llegan solas: la próxima vez que abras Excel ya tienes la versión nueva. Solo si cambian los botones de la cinta hay que instalar otra vez, y se avisará. Si algo se ve viejo, en Windows vuelve a ejecutar el instalador.
